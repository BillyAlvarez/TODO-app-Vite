# TODO App (Vite + JavaScript)

Una aplicación sencilla de lista de tareas (Todo), creada con Vite y JavaScript, que permite:

- ➕ **Añadir tareas**
- ✅ **Marcar tareas como completadas**
- 🗑️ **Eliminar tareas**
- 🔃 **Filtrar tareas** (*Todos / Pendientes / Completados*)
- 💾 **Persistencia en `localStorage`**

---

## 🚀 Tecnologías utilizadas

- [Vite](https://vitejs.dev)
- JavaScript (DOM API)
- `localStorage` para persistencia

---

## 📁 Estructura del proyecto

```plaintext
/
├─ index.html
├─ app.js          # lógica principal de la aplicación
├─ todoStore.js    # gestión de estado y almacenamiento
├─ style.css       # estilos de la interfaz
└─ main.js         # punto de entrada de la app
```
